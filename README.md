# Technocommunistic COBOL Terminal

### Experimental Economic Protocol Laboratory

> Old-school terminal aesthetics. Modern deterministic economics.

Technocommunistic COBOL Terminal is a Rust research laboratory at the intersection of finance, economics, mathematics, graph theory, mechanism design, adversarial testing, and deterministic software engineering.

Its central research question:

> Can economic contribution and distribution inside a company be represented by rules that people can inspect, challenge, reproduce, and improve?

The deterministic economic engine inside the project is called the Distribution Machine.

## Core separation

**Capital ≠ Labor ≠ Contribution ≠ Stewardship**

Labor is a contractual obligation. Capital is a separately bounded economic claim. Contribution represents evidence-backed creation of durable capability. Stewardship represents responsibility for preserving valuable systems through time.

## Economic flow

Revenue → Costs → Labor → Reserve / Reinvestment → Distributable Surplus → Economic Pools → Evidence-backed Claims → Deterministic Allocation

## Measurement principle

**NO SCORED PARAMETER WITHOUT A MEASUREMENT FUNCTION.**

**NO MEASUREMENT WITHOUT OBSERVABLE EVIDENCE.**

Economic claims should follow an inspectable chain:

Evidence → Observables → Measurement Function → Normalized Parameter → Claim → Allocation → Money

## Research method

Hypothesis → Formula → Executable Invariant → Pathological Attack → Observation → Finding → Protocol Correction

A failing pathological test can be a successful experiment. The purpose of the laboratory is to discover where an economic model breaks before real money depends on it.

Current adversarial experiments include founder gravity, invisible infrastructure, activity farming, weak-signal swarms, threshold cliffs, duplicate edges, structural identity laundering, shared bottlenecks, and failure-domain laundering.

An emerging invariant is:

> **INDEPENDENCE IS A PROPERTY OF GRAPH STRUCTURE, NOT OF LABELS.**

## The terminal

The intended operator interface is an old-school Rust terminal built with Ratatui: part economic debugger, part protocol simulator, part financial instrument.

Future workspaces include POOLS, CLAIMS, MEASUREMENTS, SIMULATION, and EVIDENCE.

A future operator should be able to select an allocation and ask: **WHY €1,086.11?** The terminal should trace that amount back through pool share, claim, measurement, observables, evidence, artifacts, dependencies, and outcomes.

## Employee-facing objective

A contributor should eventually be able to understand: what they built → what durable capability it created → what depends on it → what evidence supports it → what economic claim the protocol derives → how that may affect distribution.

The system explains economic contribution. It does not assign human worth.

## Status

**Experimental research software.** Current protocol parameters are laboratory hypotheses, not compensation policy.

Some pathological tests intentionally fail because they preserve evidence of known weaknesses in experimental models.

The core protocol is deliberately deterministic. AI may eventually assist with evidence discovery or explanation, but model output must not become authoritative economic evidence merely because a model produced it.

## Research direction

Graph-derived dependency independence → shared bottleneck detection → counterfactual removal → anti-gaming measurement → fixed-point money → reconciliation → distribution statements → Ratatui instrumentation.
